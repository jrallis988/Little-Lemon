# PULSE SPORTS — Motion Graphics Portfolio

Self-initiated case study for a fictional live sports media brand.

**Brand line:** FEEL EVERY SECOND.

## Purpose

Demonstrate professional motion graphics ability across broadcast, digital, and social — with web-based GSAP prototypes that can be replaced by final After Effects / Premiere exports.

## Stack

- React + TypeScript + Vite
- GSAP for motion prototypes
- Modern CSS design system

## Develop

```bash
cd pulse-sports
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output: `www/` (relative asset paths for subdirectory hosting).

## Replaceable media

Drop final AE/PR exports into `public/media/` and wire them into the video slots / previewer as needed.

## Case study map

Challenge → Identity → Motion Principles → Style Frames → Logo Motion → Intro → Typography → Athlete → Statistics → Score → Broadcast → Social → Storyboard → Production → Asset Library → Final System
