# ROAM Coffee — Packaging & Retail Identity

Self-initiated portfolio case study for a fictional specialty coffee brand.

**Concept:** Coffee for wherever you’re going.

## What this is

A React + TypeScript presentation of packaging, dielines, retail graphics, menus, POS, and production thinking. Cursor presents the work; the visual system is designed for print/production workflows (Illustrator / Photoshop / InDesign).

## Run

```bash
cd roam-coffee
npm install
npm run dev
```

Open the local URL (default `http://localhost:5173`).

```bash
npm run build
npm run preview
```

## Case study structure

Challenge → Concept → Identity → Product Architecture → Packaging → Dielines → Family → Labels → RTD → Gift Box → Cups → Merch → Retail → Menu → Shelf → POS → Posters → Hierarchy → Production → Gallery → Final System

## Note

ROAM Coffee is fictional. Built to demonstrate packaging design, retail graphics, typography, production design, and physical brand implementation.
