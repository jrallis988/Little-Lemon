# Little Lemon — portfolio notes

This is a **portfolio / case-study** site, not a production restaurant launch.

## Demo it
```bash
npm start
```
Walk through: Home → Layouts gallery → Menu (add items) → Order → Reserve.

## Optional public demo URL
Only if you want a shareable link — not required:
- GitHub Pages workflow on this branch, or
- Netlify / Vercel import of `cursor/little-lemon-multi-index-bc64`

Forms are wired to Formsubmit (`jjrallis@unh.edu`) for optional end-to-end demo; cart works fully offline via `localStorage`.
