# BUILT FOR THE SHIFT

Hockey performance campaign case study — athlete storytelling, product motion, and scalable After Effects systems.

**Campaign line:** BUILT FOR THE SHIFT.

## Idea

Every shift asks something different from the player. Their equipment has to answer every time.

Structure: **Athlete → Action → Performance → Product**

## Stack

- React + TypeScript + Vite
- GSAP motion prototypes
- Replaceable media slots for final AE / Premiere exports

## Develop

```bash
cd built-for-the-shift
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output: `www/`

## Case study map

Challenge → Insight → Idea → Art Direction → Motion Language → Hero Film → Athlete → Performance → Product → Athlete × Product → Social → Applications → Storyboard → AE Process → Templates → Library → System
