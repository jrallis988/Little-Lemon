# BREAKAWAY — Editorial Design Case Study

Portfolio presentation for **BREAKAWAY**, a fictional independent sports & athlete journal (*Beyond the Score.*).

This React + TypeScript archive presents the InDesign publication — it is not a replacement for the print magazine. The primary artifact remains the multi-page InDesign document (masters, styles, baseline grid, preflight, package, PDF/X).

## Run

```bash
cd breakaway
npm install
npm run dev
```

Production build (static files in `dist/`):

```bash
npm run build
npm run preview
```

From the Artistic Fountain site root, after build, open `/breakaway/dist/`.

## What’s included

- Case study narrative (challenge → concept → direction → production → digital)
- Spread viewer with fullscreen page browsing
- Typography system viewer
- Grid overlay studio
- Desktop / tablet / mobile editorial comparison
- Photography before/after compare
- Secondary promo applications

## Stack

React 19 · TypeScript · Vite · CSS (no UI framework)
