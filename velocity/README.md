# VELOCITY

Sports Poster & Art Direction Series — self-initiated graphic-design case study.

## Develop

```bash
cd velocity
npm install
npm run dev
```

Opens Vite at [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

Production assets land in `dist/` with relative paths so the case study can be served from `/velocity/dist/` or any static host.

## Focus

This presentation demonstrates sports art direction, typography, compositing stages, graphic language, print applications, and digital adaptation. The website is a portfolio vessel — craft comes first.
