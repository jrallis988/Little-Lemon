# Seascape Inn at Plaice Cove

Standalone marketing site for Seascape Inn (Hampton, NH).

Open `index.html` in a browser, or serve the folder locally:

```bash
npx serve seascape-inn
```

## Redesign notes

Compared with the previous single-file draft, this version:

- Puts **Seascape Inn** front-and-center in a full-viewport coastal hero
- Removes the emoji highlight card strip from the first screen
- Replaces boxy card chrome with quieter section layouts
- Uses a New England coastal palette (Atlantic / seafoam / mist) and Fraunces + Figtree
- Adds light motion: hero entrance, scroll reveals, and gallery/room image ease
- Keeps the same contact details, rates, amenities, and booking-by-phone flow
