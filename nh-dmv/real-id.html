REAL ID

A REAL ID driver license, non-driver ID, or passport is required to board domestic flights and enter secure federal facilities. Star-marked credentials meet the federal standard.

Book a REAL ID appointment Online document checker

When you need it

  • Flying domestically within the United States
  • Entering secure federal facilities

A valid U.S. passport also satisfies these federal ID requirements.

Before you go

  • Gather original identity documents (not photocopies).
  • Bring proof of Social Security number and New Hampshire residency.
  • Run the official online document checker so you don’t miss a visit.
  • Schedule an appointment — walk-in counter service is not available.

Renewing soon?

Many residents upgrade to REAL ID during license or non-driver ID renewal. Outside of renewal, book a dedicated REAL ID upgrade appointment.

How to spot REAL ID

REAL ID credentials are marked with a star in the top-right corner. If your current license lacks the star, plan your upgrade before you fly.
