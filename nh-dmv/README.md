# NH DMV Redesign (Concept)

Conceptual redesign of [dmv.nh.gov](https://www.dmv.nh.gov) by Artistic Fountain.

**Not an official State of New Hampshire site.** Service links point to real NH DMV / forms.nh.gov destinations where possible.

## What changed

- **Task-first homepage** — searchable, filterable service list instead of carousels and buried dropdowns
- **Appointment-led hero** — clear primary action for the appointment-based model
- **Granite civic system** — NH navy, pine, cool mist surfaces; Fraunces + Figtree
- **Secondary pages** — Appointments, REAL ID, Hours & Locations

## View locally

From the repo root:

```bash
npm start
```

Then open [http://localhost:3000/nh-dmv/](http://localhost:3000/nh-dmv/).
