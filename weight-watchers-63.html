Portfolio case study · Concept

Weight Watchers 63

63 Years of You — an independent campaign and product-vision redesign. Customer needs first. A clear look at where Weight Watchers goes next.

Role
Product design, brand narrative, interaction design, and front-end implementation
Stack
Vite · React 18 · TypeScript · Tailwind · React Router
What I owned
Campaign homepage, guided Pathways → Life → Kitchen journey, onboarding + plan matrix, Find Your Year, case study packaging, and deploy config

Thesis: 63 years taught us something: there is no single way to get healthy. So we’re building the next Weight Watchers around you.

Not affiliated with or commissioned by WeightWatchers.

Local demo

The full interactive site lives in ww63/. From the repo root:

cd ww63 && npm install && npm run dev

Then open the local Vite URL (usually http://localhost:5173). For a permanent public URL, deploy the ww63/ folder to Vercel or Netlify (Root Directory: ww63, set VITE_SITE_URL).
