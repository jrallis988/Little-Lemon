# Nick Jr. Website (Concept)

Conceptual redesign of a Nick Jr.–style kids entertainment homepage by Artistic Fountain.

**Not an official Paramount / Nickelodeon site.** Show names and playful motifs are used for demonstration only.

## Case study framing

| Goal | Approach |
| --- | --- |
| Joy-first kids IA | Color-coded Watch / Play / Explore / Create launchers |
| Caregiver trust | Dedicated Grown-Ups page with tips + sample schedule |
| Brand signal | Multicolor logo, wavy frame, soft motion, rounded chrome |
| Ship light | Static HTML/CSS/vanilla JS — no backend |

## What’s in the design

- Colorful wavy frame and rounded, kid-friendly chrome
- Hero carousel with greeting, Watch Now CTA, and Now Playing card
- “What do you want to do?” activity launchers
- Adventure Sprouts, Make Something, Friends, Play & Learn, Grown-Ups
- Dedicated **Grown-Ups** page with tips and a sample schedule
- About + accessibility notes on the kids home
- Open Graph share image for portfolio previews
- Responsive layout for desktop and mobile

## View locally

From the repo root:

```bash
npm start
```

Then open:

- Kids home: [http://localhost:3000/nick-jr/](http://localhost:3000/nick-jr/)
- Grown-Ups: [http://localhost:3000/nick-jr/grown-ups.html](http://localhost:3000/nick-jr/grown-ups.html)
