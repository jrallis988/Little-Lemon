# Nick Jr. Website (Concept)

Conceptual redesign of a Nick Jr.–style kids entertainment homepage by Artistic Fountain.

**Not an official Paramount / Nickelodeon site.** Show names and playful motifs are used for demonstration only.

## What’s in the design

- Colorful wavy frame and rounded, kid-friendly chrome
- Hero carousel with greeting, Watch Now CTA, and Now Playing card
- “What do you want to do?” activity launchers
- Adventure Sprouts, Make Something, Friends, Play & Learn, Grown-Ups
- Responsive layout for desktop and mobile

## View locally

From the repo root:

```bash
npm start
```

Then open [http://localhost:3000/nick-jr/](http://localhost:3000/nick-jr/).
