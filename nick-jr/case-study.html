Kids Home

Portfolio case study

Nick Jr. homepage concept

A joy-first preschool entertainment surface — clear kid activity paths, soft brand motion, and a caregiver area that treats screen time as purposeful.

View live prototype View Grown-Ups
RoleConcept design & build
StackHTML · CSS · vanilla JS
PagesKids home · Grown-Ups
TypePortfolio redesign

Challenge

Preschool brand sites often bury the fun behind dense nav, tiny cards, and adult marketing. The brief: make the first viewport feel like playtime, while still giving caregivers a calm place for tips and schedules.

Approach

One job per section

Watch, Play, Explore, and Create stay color-coded and full-width — kids never hunt for the next action.

Brand before headline

The multicolor logo is a hero-level signal. Greeting copy supports the brand instead of overpowering it.

Caregiver off-ramp

Grown-Ups is a dedicated page with tips, ages & stages, and a sample schedule — not a buried modal.

Ship light

Static front-end only. Carousel, search, and toasts run in a few dozen lines of vanilla JS.

Information architecture

  1. Hero — time-of-day greeting, primary Watch CTA, Now Playing card
  2. Want to do — four activity launchers as the main decision point
  3. Discover — Adventure Sprouts, Make Something, show rail
  4. Sidebar — Friends, Play & Learn, More to Explore, Grown-Ups promo
  5. Trust — About + accessibility notes for portfolio reviewers

Outcome

A clickable concept that demonstrates kids UI systems, caregiver empathy, and production-ready static delivery — ready to merge into the Artistic Fountain portfolio.
