# Disney+ · Disney Jr

A Disney+-style streaming web app focused on **Disney Jr**, with a dedicated title page for **Academy Rock**.

## Features

- Dark cinematic Disney+ chrome (nav, hero, content rails)
- Brand collection tiles with Disney Jr. as a first-class hub
- Search, Watchlist, and Continue Watching (persisted in localStorage)
- Dedicated Academy Rock page with episodes, watchlist actions, and HTML5 video playback
- Demo episode streams (public sample MP4s) until licensed video is available

## Getting started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

### Key routes

- `/` — Home
- `/disney-jr` — Disney Jr hub
- `/academy-rock` — Academy Rock title page
- `/search` — Search catalog
- `/watchlist` — Saved titles
