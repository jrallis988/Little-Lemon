# Planet Fitness — Acquisition Website

Minimalist public site focused on **club discovery**, **transparent pricing**, and a **frictionless join funnel**. Member utilities (check-in, crowd meter, workouts, digital keytag) belong in the mobile app.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Radix UI / shadcn-style primitives

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s in place

1. **Instant Club Locator** — search-first list with hours, amenities, and location detail
2. **Transparent Pricing Matrix** — Classic vs Black Card with dues, annual fee, and cancellation on-page
3. **App Hand-off Banner** — persistent CTA for existing members to use the PF app
4. **Join stub** — `/join` confirms club + plan before the multi-step checkout lands next
