# Great Bay Community College

A React website for Great Bay Community College, inspired by [greatbay.edu](https://greatbay.edu/).

## Pages

- **Home** — campus hero, highlights, program areas, student story
- **Academics** — program areas and student support
- **Admissions** — why GBCC, steps to enroll, request-info form
- **About** — mission, vision, values, campus life
- **Contact** — campus details and message form

## Getting started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm test
npm run build
```

## Stack

Create React App, React Router, Formik, Yup, custom CSS.
