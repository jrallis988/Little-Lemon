# Little Lemon — Kids Animation Portfolio

A sunny portfolio site for showcasing kids animation: character shorts, educational stories, and playful worlds.

## Stack

Static HTML, CSS, and vanilla JS. Typography: Fredoka + Nunito.

## Pages

- `index.html` — hero, selected films, showreel, about, process, contact
- `privacy.html` / `terms.html` — simple legal pages

## Develop

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

1. Replace stills in `images/work/` with your frames.
2. Drop a Vimeo/YouTube embed into the showreel modal in `index.html`.
3. Wire the contact form to Formspree, Basin, or your email API in `main.js`.
