# NHTI – Concord's Community College

A redesigned marketing website for NHTI, built with React. It keeps the college’s real programs, admissions story, and Concord campus identity while replacing the cluttered official-site pattern with a clearer, brand-first experience.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm start` — development server
- `npm run build` — production build
- `npm test` — test runner
