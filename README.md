# Atelier Rack

Production-oriented off-price retail storefront built with React, TypeScript, Vite, Tailwind CSS, shadcn-style primitives, and Zustand.

## Stack

- **React 18 + TypeScript** — modular component architecture
- **Vite** — fast local dev and production builds
- **Tailwind CSS** — design tokens for a high-end retail system
- **Zustand + localStorage** — persistent bag and filter state
- **React Router** — catalog, PDP, and shell navigation

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run preview
```

## What's included in this foundation

- Global CSS layout tokens (shelf width, rail, promo/header heights, deal/inventory colors)
- App shell with sticky header, promo bar, footer, and error boundary
- Catalog grid with faceted filters, sort, skeletons, empty state, and quick view
- Product detail page with image thumbnails, size/color selection, and sticky add-to-bag
- Slide-over bag with promo codes, savings math, and guest-friendly checkout CTA

## Brand direction

**Atelier Rack** — cool stone neutrals, ink typography (Syne + DM Sans), and signal red for off-price savings — aimed at contemporary high-street retail rather than a generic prototype look.
