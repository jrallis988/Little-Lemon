# Morgan Hale for U.S. Senate

A modern, fast, accessible campaign website for a New Hampshire Senate candidate—built for independent and local voters.

## Stack

- **Next.js 14** (App Router) — Vercel-ready static/ISR
- **Tailwind CSS** — granite, pine, amber design tokens
- **Lucide React** — stroke icons
- **Merriweather + Source Sans 3** — serif headings, high-legibility body

## Sections

1. **Hero** — brand-forward value prop + Join / Chip In CTAs
2. **Issues** — expandable pillars (costs, Main Street, lands, education)
3. **Events** — filterable NH county calendar with Add to Calendar
4. **Meet the Candidate** — local roots narrative
5. **Action Center** — lawn sign, volunteer, newsletter forms with validation
6. **Donate** — contribution intent form + FEC-style disclaimer
7. **Footer** — paid-for-by, privacy, accessibility links

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Connect the repo to Vercel. No special env vars required for the static demo forms.
